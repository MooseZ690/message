# Message

A web-based messaging application built using **Python, Flask, HTML, CSS and JavaScript**.

## Overview

Message is a web application designed to allow users to communicate through an online messaging system. The project focuses on creating a functional, user-friendly messaging experience while demonstrating the use of Python programming, web development, databases, and user interaction.

## Features

* User account functionality
* User authentication
* Sending and receiving messages
* Database storage
* Web-based user interface
* Dynamic pages using Flask
* HTML templates for different parts of the application
* CSS styling for the user interface
* JavaScript for client-side functionality

## Technologies Used

* **Python** – Main programming language
* **Flask** – Web application framework
* **HTML** – Page structure
* **CSS** – Styling and layout
* **JavaScript** – Client-side functionality
* **Database** – Storing application and user data

## Project Structure

```text
message/
├── app.py
├── templates/
├── static/
├── database/
└── ...
```

`app.py` contains the main application logic and Flask routes.

The `templates` folder contains the HTML pages used by the application.

The `static` folder contains resources such as CSS and JavaScript used by the website.

## How It Works

The application runs as a Flask web server. When a user interacts with the website, their request is handled by the Python application.

The application can then:

1. Receive the user's request.
2. Process the required information.
3. Interact with the database when necessary.
4. Perform the appropriate operation.
5. Return an updated web page to the user.

This allows the different parts of the application to work together as a complete messaging system.

## Running the Project

### Requirements

You will need:

* Python 3
* Flask
* The dependencies listed in the project

### Installation

Clone the repository and install the required dependencies.

```bash
git clone https://github.com/Moosez690/message.git
cd message
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

The application can then be accessed through the local Flask server.
